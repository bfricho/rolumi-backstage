# ROLUMI Design System

Praktická vrstva existujúcej identity ROLUMI pre web, sociálne siete, dokumenty a ďalšie digitálne alebo tlačové výstupy.

## Zásady

1. **Pevnosť.** Vizuál má pôsobiť stabilne, remeselne a kompetentne.
2. **Jasnosť.** Hierarchia je zreteľná, text priamy a rozloženie funkčné.
3. **Kontrast.** Grafitová, žltá a biela vytvárajú hlavný vizuálny rytmus.
4. **Autenticita.** Prednosť majú skutočné materiály, ľudia, predajňa a realizácie.
5. **Striedmosť.** Žltá je signál a akcent, nie výplň každého prvku.
6. **Geometria.** Pevná mriežka a diagonálny motív vychádzajú zo symbolu loga; oválne masky sú vyhradené pre schválené fotografické kompozície.

## Obsah

- `foundations.md` - farby, typografia, spacing, layout a základná geometria,
- `photography.md` - fotografický obsah, oválne kompozície, veľkoformátové obrazy, čisté verzie a radius,
- `logo.md` - varianty loga, pozadia, ochranná zóna a zakázané použitie,
- `components.md` - základné digitálne komponenty,
- `socials.md` - formáty, kompozícia, znak a bezpečné zóny pre sociálne siete,
- `tokens.css` - implementačné CSS premenné,
- `tokens.json` - strojovo čitateľné tokeny,
- `index.html` - vizuálny katalóg systému.
- `socials/index.html` - samostatná živá podstránka pre Facebook a Instagram,
- `examples/` - schválené vizuálne referencie obrazového smeru,
- `fonts/InterVariable.woff2` - lokálny variabilný font Inter 4.1,
- `fonts/LICENSE.txt` - licencia SIL Open Font License k fontu Inter.

## Status pravidiel

- **Brand source:** priamo potvrdené pôvodným manuálom alebo SVG podkladmi.
- **System rule:** praktické pravidlo doplnené pre konzistentnú implementáciu.
- **Open:** chýbajúci podklad alebo rozhodnutie, ktoré sa nesmie vydávať za schválené.

## Rýchly štart

Pre nový vizuál použi biele alebo grafitové pozadie, jednu dominantnú textovú hierarchiu v Interi, žltú ako akcent, autentickú fotografiu a správny variant loga. Fotografický režim vyber podľa `photography.md`; ovál nepoužívaj automaticky. Nepridávaj ďalší font, novú hlavnú farbu ani efekt na logo.
