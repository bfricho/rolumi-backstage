# Otvorené úlohy brand systému

Kompletný kontext a priority sú v [BRAND_AUDIT.md](./BRAND_AUDIT.md).

## Priorita A — pred novým webom

- [ ] Overiť, či existuje dodaný samostatný symbol pre všeobecné použitie mimo sociálnych sietí.
- [ ] Pripraviť favicon a malú digitálnu značku pre rozmery, v ktorých je celé logo nečitateľné.
- [ ] Doplniť tone of voice po spracovaní stratégie a positioningu.
- [ ] Rozhodnúť, či descriptor `STAVEBNINY` zostane univerzálnou súčasťou loga aj po transformácii spoločnosti.

## Priorita B — počas tvorby webu

- [ ] Doplniť produkčné stavy komponentov podľa reálnych potrieb webu: mobilná navigácia, disabled, loading, success, validačná chyba a prázdny stav.
- [ ] Vybrať základnú sadu ikon a určiť veľkosti, hrúbku ťahu a pravidlá použitia.
- [ ] Na hotovej implementácii overiť klávesnicu, focus, kontrast, alternatívne texty a zväčšenie textu.

## Priorita C — produkcia a prevádzka

- [ ] Otestovať a definitívne schváliť minimálnu digitálnu a tlačovú veľkosť loga.
- [ ] Overiť, či existujú tlačové logá vo formáte PDF, EPS alebo SVG s definovaným CMYK workflow.
- [ ] Postupne rozšíriť knižnicu schválených fotografií o ľudí pri práci, dopravu a ďalšie dokončené realizácie.
- [ ] Zaviesť pri fotografiách evidenciu autora, licencie alebo súhlasu, dátumu a povoleného použitia.
- [ ] Pripravovať praktické šablóny až podľa konkrétnej potreby: ponuka, prezentácia, hlavičkový dokument, e-mailový podpis alebo označenie prevádzky.

## Dokončené

- [x] Dokončiť a schváliť formáty pre Facebook, Instagram, Stories a Reels.
- [x] Zdokumentovať základy, logá, farby, typografiu, layout, fotografiu a digitálne komponenty.
- [x] Pripraviť CSS a JSON design tokeny a živý vizuálny katalóg.
- [x] Validovať lokálne assety, odkazy, kontrast a načítanie HTML katalógov bez chýb.
